# VezoBox | Trans M&S website

Public information and release history for the VezoBox | Trans M&S website.
Website and application source code remain private.

## Independent versions

- **Translation website preview:** 0.1.0
- **Translation application development version:** 2.8.3
- **Customer installer:** not published

The website is currently a local preview. No public hosted website URL has been published.
Its own version history starts at 0.1.0; it does not inherit the Security website's version.

## Product

VezoBox | Trans M&S introduces the Windows translation application, speech translation and subtitle display.
The website includes an interactive caption illustration; it does not perform live browser translation.

## App updates

Windows application releases will be distributed separately through [VezoBox-Translation-Updates](https://github.com/SATLANIKO/VezoBox-Translation-Updates).
Website releases do not create or increment Windows app releases.
